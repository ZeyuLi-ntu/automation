2. CIMB 的 Cookie 提示遮住两行视觉证据。新快照在关闭提示后采集，旧失败快照仍保留。
3. 两路曾同时把 `<100,000` 改成 `99,999`。现在禁止边界算术，并核实金额端点在各路线自己的原文/转录中实际存在。
4. 金额上限的 `<` 与 `≤` 分开保存。CIMB 迎新的定存范围是条款表中的最低/最高存入金额，资格资产门槛保留为独立条件，不能互相替代。
5. CIMB WWFD 表头实际出现 `$S$`，只对该明确重复币种符号做规范化；不宽泛删除文字、币种或金额运算。
6. 关联 PDF 补充了普通在线/WWFD 的金额上限、有效期、WWFD 在线渠道的新资金豁免；现金奖励 PDF 的日期和资格不得覆盖基础产品。
