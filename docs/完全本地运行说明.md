# 完全本地运行说明

更新：2026-09-27。

## 本地模型的 token 是什么

token 是模型处理输入和输出的单位。Qwen 在本机也使用 token 和上下文窗口，但不存在按 token 向 GPT 支付 API 费用。更多输入会增加本地推理时间、显存/内存占用及电力消耗。缓存减少重复计算。维护代码时使用的聊天服务，与双击本地脚本执行的项目流程是两件事；脚本不把任务发回聊天服务。

## 实际流程

1. 本机 Python/Playwright 打开银行官网，保存原文、PDF、截图、网址和采集时间。访问官网需要互联网。
2. 文字路线（LLM）读取网页/PDF文字，从原文提取利率、币种、期限、金额和资格等字段。
3. 视觉路线（VLM）读取截图或PDF页面图像，单独提取同类字段，不读取文字路线的答案。
4. 两路都调用本机 `http://127.0.0.1:11434` 的 Ollama。目前文字和视觉均是本地 `qwen3.5:4b`，顺序运行以适应显存；不是两个不同模型。GPU负责模型推理，CPU负责浏览器、解析、规则计算等。
5. Python 做字段比较和规则检查。核心字段不一致、缺失或格式异常进入人工复核；一致只代表通过该项检查，不代表完整条款已经人工确认。相同模型可能共同漏读，仍需要原文证据及人工入口。
6. Personal优先、最高报价、期限归组、稳定并列、颜色和历史滚动由固定代码处理。Node本地库准备输入，桌面Excel生成两份新文件并计算公式；这些步骤不调用模型。
7. 人工入口在本机 `127.0.0.1:8765`，修正与审计记录保存在本地。确认历史底稿仍由用户明确执行。

已有证据的提取、核验和插表可以本地执行；新一周采集必须联网访问银行，不能完全断网获得最新市场信息。

## 已落实的本地限制

- 模型分发只允许 Ollama，其他 provider 直接报错。
- 旧 OpenAI 入口已移除请求实现，只保留禁用提示，不读取密钥。
- Ollama 地址只接受回环地址；本地请求不经过系统代理，也不跟随重定向。
- 拒绝 cloud 型号及指向云服务的模型别名；启动脚本设置 OLLAMA_NO_CLOUD。
- 2026-09-27 分别执行文字与图片短请求，两路均显示 GPU 参与，模型驻留显存约 2.91 GiB（本次小请求4096上下文）。该检查只证明运行位置，不代替利率准确率验证。

验证记录：data/local-only-check-20260927.json。无需提供或配置任何 GPT API 密钥。

## Maybank 新链接

已读取《利率链接.xlsx》中 Maybank / SGD / 促销所在记录，目前是 D47。每次新运行重新读取该记录，不再固定访问旧PDF地址；若链接位置移动，按银行、币种、类别匹配。重复记录、空链接、非登记官网域名会报错。

网页采集范围限定为 Deposits Bundle Promotion，保留实际表格及该节条件，不混入后面的 Standalone。范围匹配失败就停止，不随意换其他表格。边界逻辑已用本地合成页面验证，但本机访问真实网站仍有 HTTP/2 错误或超时，真实网页的新采集尚未成功验收。旧的导入证据和已生成表格保持原状态，不冒充新采集。

## 使用与部署边界

“一键运行.cmd”“人工修正入口.cmd”“重新生成已验证表格.cmd”均从本机启动，不需要把任务发送给 GPT。实时一键流程目前仍可能因 Maybank 网络连接失败而停止。

当前电脑已安装所需运行库，部分 Python、Node、PDF 工具路径来自 Codex 安装的本地工具目录；调用这些磁盘上的工具不等于调用 GPT。尚未制作可搬到另一台电脑直接安装的独立发行包。若需要彻底脱离 Codex 安装目录，后续可单独部署并配置这些本地依赖，无需改变本地双路核验原理。
