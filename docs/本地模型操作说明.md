# 本地模型操作说明

## 当前选择

- 引擎：Ollama，本机HTTP服务，默认地址`http://127.0.0.1:11434`。
- 初始文字模型与视觉模型：`qwen3.5:4b`。
- 本机已读取到RTX 4060 Laptop（8GB显存），系统内存约16GB。4B是首个试验配置，不保证所有长网页都能顺畅处理。
- 模型本地推理无需OpenAI账户或API密钥，没有按请求收取的云API费用。
- 模型文件约3.4GB；安装包、浏览器和运行缓存另占空间。首次下载需要联网，采集银行网站也需要联网。

官方资料：[模型文件与图片能力](https://ollama.com/library/qwen3.5:4b)、[Ollama Windows](https://docs.ollama.com/windows)、[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)。

## 1. 安装并验证模型

本机已于2026-09-25改用完整官方CLI 0.34.4，解决旧安装缺失NVIDIA运行库的问题，RTX 4060已实际参与文字和图片推理。项目使用`config/ollama.runtime.local.json`指定的运行库，模型位于`F:\Ollama\Models`。旧0.18.2安装保留以便回退，不再被项目启动脚本选用。其他电脑可从[Windows下载页](https://ollama.com/download/windows)安装。

本机在项目目录运行以下命令。启动脚本优先读取已验证的本地运行库配置，隐藏启动本机服务，并对新启动的服务关闭云功能：

```powershell
powershell -NoProfile -File scripts/start_local_model.ps1
powershell -NoProfile -File scripts/run.ps1 doctor --config config/project.local.json
```

`doctor`检查服务、模型能力及已加载模型是否使用GPU，不测准确率。模型在空闲一段时间后可能卸载；此时不能通过`doctor`确认GPU，需在实际推理期间检查。日志和当前服务信息位于`data/local-model/`。若11434端口被旧版本占用，启动脚本会明确报错，避免误用旧版本。完整运行库保存在`data/ollama-repair-20260925/v0.34.4`，这是正在使用的程序目录，应保留。

默认两路用同一个模型，以不同输入分两次请求：第一路只有网页文字，第二路只有截图和页面标识。它们不读取对方答案，但可能产生相关错误；真实试点期间仍逐项人工核对。

## 2. 安装网页采集依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[live]"
.\.venv\Scripts\python -m playwright install chromium
```

电脑没有`python`命令时，可用本项目`scripts/run.ps1`使用的Python路径创建虚拟环境；运行`Get-Content scripts/run.ps1`可查看查找规则。

## 3. 小样本参数

已有`config/project.local.json`，默认参数是：

| 参数 | 初始值 | 含义 |
| --- | --- | --- |
| text_model / vision_model | qwen3.5:4b | 可分别更换 |
| num_ctx | 16384 | 本次上下文长度，不照搬模型宣称的最大长度 |
| num_predict | 4096 | 预留结构化结果输出长度 |
| max_text_chars | 6000 | 每家银行每批文字上限 |
| max_images | 2 | 每批截图上限 |
| timeout_seconds | 600 | 本地推理超时时间 |

超过上限会失败并进入待处理状态。接入真实页面时，应先定位完整利率表及关联条款，再验证批次是否能容纳；当前代码没有自动将长银行页面拆分再无损合并的能力。不得只截掉尾部条款让测试通过。

`image_token_estimate`用于预估图片上下文，不是精确计数。真实试点要记录实际输入/输出token数、耗时和`ollama ps`中CPU/GPU加载情况。若显存不够，先减少同批无关页面并保留全部有效证据，再调整模型或上下文。

`OLLAMA_NO_CLOUD=1`是Ollama提供的禁用云功能选项，需要在启动服务前设置并重启Ollama。项目本身也拒绝云型号、远程服务地址和指向云端的模型别名。详见[官方FAQ](https://docs.ollama.com/faq)。

## 4. 运行真实试点前还需填写

模型配置之外，还有三个必须准备的部分：

1. 启用已核实的官网来源，包含利率页与关联条件页。
2. 产品目录和预期期限：把漏产品/漏期限变成可检查的问题。
3. 模板映射：确定每个产品对应16号模板哪一行，新产品插在何处。

这些不是通过安装模型就自动完成的。详细顺序见[真实试点计划](下一步真实试点计划.md)。
